# Open tools. Connected systems.

ASV Soft builds open-source applications and .NET libraries for the world where software meets hardware — from a single protocol to a complete ground station.

Explore our projects, documentation, and ecosystem at **[asv.me](https://asv.me/)**.

## Applications

| Project | Description |
| --- | --- |
| [Asv.Drones](https://github.com/asv-soft/asv-drones) | A modular ground control station for ArduPilot and PX4. Connect your vehicles, work with telemetry, and extend your workspace with plugins. |
| [Asv.Drones.Gbs](https://github.com/asv-soft/asv-drones-gbs) | An RTK ground base station service that connects GNSS receivers and delivers corrections over MAVLink. |
| [Asv.Drones.Sdr](https://github.com/asv-soft/asv-drones-sdr) | Explore SDR payload integration, spectrum analysis, and mission-specific controls in the drone stack. |

## Protocols & data

| Project | Description |
| --- | --- |
| [Asv.Mavlink](https://github.com/asv-soft/asv-mavlink) | MAVLink for .NET. Connect vehicles and payloads, receive telemetry, send commands, and build your own tools. |
| [Asv.Gnss](https://github.com/asv-soft/asv-gnss) | Read GNSS data and work with receiver protocols, from NMEA and RTCM to UBX, SBF, and more. |
| [Asv.Ulog](https://github.com/asv-soft/asv-ulog) | Inspect PX4 ULog files, extract messages, and read recorded parameters with a parser and command-line tools. |

## User interfaces

| Project | Description |
| --- | --- |
| [Asv.Avalonia](https://github.com/asv-soft/asv-avalonia) | Build cross-platform Avalonia applications with reusable controls, dialogs, theming, and workspace tools. |

## Foundations

| Project | Description |
| --- | --- |
| [Asv.Common](https://github.com/asv-soft/asv-common) | The shared foundation: I/O, configuration, protocol routing, serialization, and application infrastructure. |
| [Asv.Sdr](https://github.com/asv-soft/asv-sdr) | Digital signal processing building blocks with a fluent API for composing signal-processing workflows. |
| [Asv.Audio](https://github.com/asv-soft/asv-audio) | Reactive audio pipelines for capture and playback devices, with Opus encoding and decoding. |
| [Asv.Hal](https://github.com/asv-soft/asv-hal) | A common interface for displays, keyboards, LEDs, switches, and other hardware components. |
